# Maps 운영 가이드

## 1) 라이선스/정책
- 지도 렌더러: `MapLibre GL JS`
  - 라이선스: BSD-3-Clause.
  - 코드 사용 시 라이선스 고지(OSS NOTICE)를 유지한다.
- 기본 데이터/타일: `OpenStreetMap` 계열 소스
  - OSM 데이터 사용 시 ODbL(출처 표기 + 파생 데이터 의무) 준수.
  - 타일은 제공자별 ToS, 트래픽 제한, 상업 사용 제한을 반드시 확인한다.

## 2) 스타일/타일 소스 선택 기준
- 개발/로컬: 공개 데모 스타일(`https://demotiles.maplibre.org/style.json`) 사용 가능.
- 스테이징/운영: 아래 기준으로 공급자 결정.
  - 요청량/요금 정책: 월 최대 요청량, burst 제한, 초과 과금.
  - SLA/지역 커버리지: 국내 사용자 기준 지연(latency), 장애 공지 채널.
  - 캐시 허용 범위: CDN/엣지 캐시 허용 여부.
  - 법적 고지: attribution 문구 요구사항.

## 3) Attribution(출처 표기) UI 정책
- 지도 화면에 기본 attribution 컨트롤을 항상 노출한다.
- 모바일에서도 숨김 금지. compact 모드는 허용하되 클릭 시 전체 출처가 보여야 한다.
- 배경지도/데이터 소스를 변경하면 attribution 문구도 함께 업데이트한다.

## 4) 장애/성능 저하 대응
- 증상
  - 타일 404/429/5xx 증가
  - 지도 로딩 지연, 빈 타일(blank tile), 스타일 JSON fetch 실패
- 즉시 조치
  1. 스타일 URL을 백업 소스로 전환(환경변수/설정 스위치).
  2. 지연이 큰 경우 클러스터 강화를 통해 초기 렌더링 부하 축소.
  3. Nearby API는 `Search this area` 버튼 모드 유지(auto-search 비활성화 권장).
- 복구 확인
  - 지도 초기 로딩 시간, 타일 에러율, Nearby API p95 재확인.

## 5) 오프라인/사내 대안(후속)
- 사내 타일 캐시(예: CDN + reverse proxy)로 인기 줌 레벨(도심권) 선캐시.
- 완전 오프라인 요구 시
  - 벡터 타일 서버(사내) + 자체 스타일 배포
  - 배포 크기/업데이트 주기/데이터 최신성 운영 계획을 별도 수립.
