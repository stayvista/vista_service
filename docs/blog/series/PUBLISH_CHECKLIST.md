# StayVista 기술 개발기 발행 체크리스트

## 문체/형식
- 존댓말 문체로 작성되었는지 확인합니다.
- 제목/한 줄 요약/핵심 포인트가 명확한지 확인합니다.
- 문단 길이가 과도하게 길지 않은지 확인합니다.
- 코드 블록/메트릭/테이블명이 실제 코드와 일치하는지 확인합니다.

## 기술 정확성
- 클래스/함수/테이블명 오탈자가 없는지 확인합니다.
- 운영 지표(metric) 이름이 실제 계측명과 일치하는지 확인합니다.
- API 경로/HTTP 메서드가 실제 구현과 일치하는지 확인합니다.
- 실패 경로/degrade 경로 설명이 실제 동작과 일치하는지 확인합니다.

## 운영 관점
- "왜 중요한가"가 성능/정합성/비용/운영성 관점에서 설명되는지 확인합니다.
- 장애 시나리오와 대응 방향이 포함되어 있는지 확인합니다.
- 개선 과제가 다음 액션으로 자연스럽게 이어지는지 확인합니다.

## 시리즈 연결성
- 앞/뒤 글과의 연결 문장이 있는지 확인합니다.
- 중복된 설명이 과도하지 않은지 확인합니다.
- 같은 주제의 글 사이에서 용어가 일관적인지 확인합니다.

## 배포 전 최종 점검
- front matter(`title/slug/order/prev_slug/next_slug/status/excerpt/read_time_min/tags`)가 채워져 있는지 확인합니다.
- 시리즈 인덱스([README.md](/Users/seungyoonkim/dev/side_projects/stayvista/docs/blog/series/README.md)) 링크가 최신인지 확인합니다.
- 발행 순서에 맞게 내부 CMS 초안 순번이 정렬되어 있는지 확인합니다.
