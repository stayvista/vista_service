# U-0102 — 검색 결과 페이지(리스트/필터/정렬/페이지네이션)



## Goal
`/search`에서 숙소 리스트를 빠르게 보여주고, 필터/정렬/무한스크롤(또는 더보기) UX를 제공한다.



## Scope
- UI components:
      - SearchSummaryBar(조건 요약 + 수정)
      - FilterPanel(가격/평점/편의시설)
      - SortDropdown
      - PropertyCardList
      - Pagination(더보기 버튼 or infinite scroll)
    - 상태 관리:
      - URL query ↔ 상태 동기화(필터 변경 시 querystring 업데이트)
      - debounce 검색(필터 변경 후 300ms)



## API integration
- `GET /v1/search/properties` 호출
    - cursor 기반 페이지네이션:
      - 첫 요청: cursor 없음
      - 더보기: next_cursor 사용
    - 에러 처리:
      - 429 RATE_LIMITED: “잠시 후 다시 시도” 토스트
      - 500: 재시도 버튼



## Performance
- 스켈레톤 UI(첫 로딩/더보기)
    - 이미지 lazy-load
    - list virtualization(선택: 200개 이상일 때)



## Acceptance Criteria
- 필터/정렬 변경이 즉시 반영된다
    - 더보기로 다음 페이지를 불러올 수 있다
    - p95 렌더링이 과도하게 느려지지 않음(로컬 기준)
