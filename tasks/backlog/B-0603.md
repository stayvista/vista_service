# B-0603 — Seed 데이터/로컬 데모 시나리오 생성



## Goal
프론트/백엔드/검색/부하테스트를 빠르게 돌리기 위한 표준 Seed 데이터를 만든다.



## Scope
- MySQL seed:
      - properties 10,000
      - room_types 30,000
      - inventory_night: 핫키 room_type 1개는 365일치 total=1000
    - OpenSearch seed:
      - properties index upsert
    - 스크립트:
      - `services/tools/seed/seed_local.kt` 또는 SQL + 작은 runner



## Non-goals
- 실제 제휴사 데이터 수집은 v2



## Acceptance Criteria
- 로컬에서 seed 실행 → web-user에서 검색 결과가 바로 보임
    - 부하테스트(B-0601)가 seed 데이터 기준으로 동작
