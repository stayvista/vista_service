# B-0404 — Local RAG: Embedding 모델 + Vector Store (오프라인)

## Goal
추천 근거를 위해 로컬 임베딩 + 벡터 검색 기반 RAG를 구축한다.

## Scope
- `EmbedClient.embed(text)` 제공
- local embed endpoint 연동 (예: `bge-m3`)
- 벡터 검색 저장소 구성 (local/offline)
- `tool.search_items()`에 근거 문서(source) 반환 보장

## Data Contract
- source 문서 필드:
  - `doc_id`
  - `title`
  - `snippet`
  - `source_type`

## Acceptance Criteria
- `tool.search_items()`가 항상 `source`를 반환
- LLM 응답이 최소 2개 근거 문서를 인용
