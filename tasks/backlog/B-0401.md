# B-0401 — Geo Service: 주변 관광지(POI) 조회 API



## Goal
사용자의 현재 위치 기준으로 주변 관광지(POI: Point of Interest)를 추천/검색한다.
    지도/리스트 UI(U-0402)에서 사용한다.



## Scope
- `GET /v1/geo/pois/nearby?lat&lng&radius_m&category&limit`
    - 데이터 소스(v1):
      - (선택1) OpenSearch geo_distance query
      - (선택2) MySQL + spatial index(초기에는 단순)
      - (선택3) 외부 API(카카오/구글) — v2 권장(키/쿼터/비용 이슈)
    - 캐시:
      - geohash/타일 기반 캐시(짧은 TTL)



## API Contract
### GET /v1/geo/pois/nearby
Query:
- lat, lng (필수)
- radius_m (기본 2000)
- category=attraction|food|shopping|museum ...
- limit (기본 20, 최대 50)
200 Response:
```json
{
  "request_id": "01J0...",
  "data": {
    "items": [
      {
        "poi_id": "poi_100",
        "name": "City Museum",
        "category": "museum",
        "distance_m": 420,
        "location": {
          "lat": 37.5,
          "lng": 127.04
        }
      },
      {
        "poi_id": "poi_101",
        "name": "River Park",
        "category": "attraction",
        "distance_m": 780,
        "location": {
          "lat": 37.49,
          "lng": 127.03
        }
      }
    ]
  }
}
```



## Latency & limits
- 목표: p95 < 150ms
    - 보호:
      - rate limit(geo는 호출 빈도 높음)
      - radius_m 최대 10000 제한



## Testing
- seed POI 100개 넣고 반경 내 결과 정렬(distance asc) 확인
    - 캐시 hit 시 latency 감소 확인



## Acceptance Criteria
- 현재 위치 기반으로 주변 POI 리스트가 반환된다
    - U-0402에서 바로 사용할 수 있는 필드(distance_m, category) 포함
