# A-0201 — 티켓/체험 상품 관리 UI(product/event/inventory)



## Goal
Admin에서 티켓/체험 상품과 이벤트(날짜/시간), 재고(total)를 관리한다.



## Scope
- products list + create form
    - product detail:
      - events list(날짜/시간)
      - inventory edit(total)
    - sold out/상태 관리



## API integration
- `POST /v1/admin/tickets/products`
    - `POST /v1/admin/tickets/products/{productId}/events`
    - `PUT /v1/admin/tickets/events/{eventId}/inventory`



## Acceptance Criteria
- event total을 100으로 세팅 후 user 구매(U-0201)가 가능
