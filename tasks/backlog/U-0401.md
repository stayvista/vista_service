# U-0401 — 챗봇 UI(추천 카드/후속 질문, 모바일 우선)



## Goal
챗봇 화면에서 대화형으로 추천을 받고, 추천 카드를 통해 상품/POI로 이동할 수 있게 한다.



## Scope
- route: `/chat`
    - UI:
      - ChatMessageList(사용자/봇)
      - Composer(input + send)
      - RecommendationCards(POI/숙소/티켓/패키지)
      - FollowupChips(클릭하면 메시지 전송)



## API integration
- `POST /v1/chat/recommend`
    - optimistic UI(전송 즉시 로딩 버블)
    - 실패 시 재시도 버튼



## Acceptance Criteria
- 추천 카드 클릭 시 해당 상세로 이동한다
    - followup 칩이 동작한다
