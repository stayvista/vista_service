# U-0103 — 숙소 상세 페이지(갤러리/룸타입 선택/가격 요약)



## Goal
숙소 상세 페이지에서 정보/사진/위치/룸타입 목록을 제공하고,
    사용자가 룸타입과 날짜를 선택해 예약 플로우로 진입할 수 있게 한다.



## Scope
- UI blocks:
      - ImageGallery(캐러셀)
      - PropertyMeta(이름/평점/주소)
      - MapPreview(간단 지도 또는 static map 이미지)
      - RoomTypeList:
        - 룸타입 카드(정원/가격/정책)
        - “예약하기” 버튼
      - PriceBreakdown(세금/수수료는 v1 단순)



## API integration
- `GET /v1/properties/{id}`
    - `GET /v1/properties/{id}/room-types`
    - 예약 진입:
      - 룸타입 선택 후 `예약하기` 클릭 → `/properties/{id}/book?room_type_id=...`



## Edge cases
- 룸타입이 없거나 INACTIVE면 “현재 예약 불가”
    - 이미지 URL 없으면 placeholder



## Acceptance Criteria
- 상세 페이지에서 룸타입을 보고 예약 버튼으로 다음 단계로 이동 가능
