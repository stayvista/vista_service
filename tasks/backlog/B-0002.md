# B-0002 — 로컬 인프라 docker-compose(MySQL/Redis/Kafka/OpenSearch) 세팅



## Goal
개발/테스트에서 운영 환경(AWS RDS/Aurora, ElastiCache, MSK, OpenSearch)과 최대한 유사한 컴포넌트를 로컬에서 띄운다.



## Scope
- `services/docker/docker-compose.yml`에 아래 포함:
      - MySQL 8 (UTF8MB4, slowlog 옵션, healthcheck)
      - Redis (healthcheck)
      - Kafka(KRaft 모드) 1노드(로컬용)
      - OpenSearch 단일노드 + nori(선택)
    - 개발자 편의:
      - volume 명시, 포트 명시, 초기 DB 생성
      - `make infra-up`, `make infra-down`(선택)



## Non-goals
- 운영과 100% 동일한 보안/IAM(예: MSK IAM)은 로컬에서 완벽 재현 불가
    - 다중 브로커/멀티 AZ는 로컬에서 생략



## Compose requirements
- 모든 서비스에 healthcheck를 두고, app은 health를 기다린 뒤 기동(또는 재시도)
    - 포트 충돌 방지를 위해 host port는 13306/16379/19092/9200 사용



## Validation checklist
- MySQL 접속: `mysql -h 127.0.0.1 -P 13306 -u root -p`
    - Redis ping: `redis-cli -h 127.0.0.1 -p 16379 ping`
    - Kafka produce/consume smoke
    - OpenSearch health: `GET http://localhost:9200/_cluster/health`



## Acceptance Criteria
- `docker compose up -d` 한 번으로 인프라가 모두 기동
    - `services`에서 Testcontainers 없이도 로컬 수동 테스트 가능
    - RUNBOOK에 로컬 트러블슈팅(포트/볼륨/초기화) 추가
