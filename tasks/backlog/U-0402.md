# U-0402 — 주변 추천 UI(현재위치/리스트/지도)



## Goal
사용자의 현재 위치를 기반으로 주변 POI를 리스트/지도 형태로 보여준다.



## Scope
- route: `/nearby`
    - 기능:
      - 위치 권한 요청(거부 시 수동 좌표 입력)
      - 카테고리 탭(맛집/관광/쇼핑/전시)
      - 리스트 + (선택) 간단 지도



## API integration
- `GET /v1/geo/pois/nearby`
    - 위치 변화가 크지 않으면 캐시된 결과 사용(클라 캐시 30초)



## Acceptance Criteria
- 현재 위치 허용 시 2초 내 주변 리스트가 보인다(로컬 기준)
    - 카테고리 변경 시 결과가 갱신된다
