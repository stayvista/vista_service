# A-0103 — 재고 캘린더 UI(룸타입별 total 설정)



## Goal
운영자가 룸타입별 재고(total)를 캘린더 형태로 편하게 수정할 수 있게 한다.



## Scope
- 화면:
      - RoomType selector(검색/드롭다운)
      - Month calendar grid(일자별 total 표시)
      - Bulk edit:
        - start_date/end_date 선택 + total 입력 + 적용
    - 상태:
      - 저장 전 변경값은 client state에 임시 저장
      - apply 시 서버 반영



## API integration
- `PUT /v1/admin/room-types/{roomTypeId}/inventory`
    - conflict(409 INVENTORY_TOTAL_BELOW_COMMITTED) 시:
      - conflict_date를 UI에서 강조(가능하면 server details에 포함)
      - 사용자가 더 큰 total로 재시도 유도



## Acceptance Criteria
- 1달 범위 재고를 20으로 설정하는 작업이 10초 내 가능(UX 기준)
    - booking hold가 해당 날짜에 정상 동작
