# A-0101 — web-admin 스캐폴딩(사이드바/라우팅/권한 가드)



## Goal
운영자가 숙소/재고/티켓/바우처를 관리할 수 있는 Admin UI 기본 골격을 만든다.



## Scope
- layout:
      - Sidebar(메뉴)
      - TopBar(환경/로그아웃)
      - Content router
    - routes:
      - `/admin/properties`
      - `/admin/properties/:id`
      - `/admin/inventory`
      - `/admin/tickets`
      - `/admin/vouchers`
    - 권한(v1 stub):
      - `X-Admin-Id` 헤더(임시) 또는 basic login 스텁



## Acceptance Criteria
- 각 메뉴가 정상 라우팅되고 빈 페이지라도 렌더링된다
    - 공통 API client가 존재(에러 envelope 처리 포함)
