# B-0301 — Package Product 모델(숙소+티켓+체험 번들)



## Goal
패키지(숙소 + 티켓/체험) 상품 모델을 정의한다.
    패키지는 단일 구매로 여러 컴포넌트를 예약해야 하므로, 구성품/조건/가격을 명확히 모델링해야 한다.



## Scope
- package_product:
      - 구성품 리스트(components): accommodation(room_type + nights), ticket(event + qty), experience(...)
      - 가격: base + discount (v1은 고정가)
    - Admin CRUD:
      - `POST /v1/admin/packages`
      - `GET /v1/admin/packages/{id}`
    - User read:
      - `GET /v1/packages`
      - `GET /v1/packages/{id}`



## Non-goals
- 동적 구성(옵션 선택) v2
    - 복잡한 가격 규칙/프로모션 v2



## Package document example
```json
{
  "package_id": 7001,
  "name": "Wanderly Seoul Weekend",
  "status": "ACTIVE",
  "components": [
    {
      "type": "ACCOMMODATION",
      "room_type_id": 2001,
      "nights": 2,
      "rooms": 1
    },
    {
      "type": "TICKET",
      "event_id": 5001,
      "quantity": 2
    }
  ],
  "price": {
    "currency": "KRW",
    "amount_total": 320000
  }
}
```



## Acceptance Criteria
- package 상품을 생성/조회할 수 있다
    - B-0302 Saga에서 참조 가능한 형태로 components가 모델링된다
