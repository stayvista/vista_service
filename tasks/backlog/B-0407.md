# B-0407 — LLM 사용 여부 라우팅 정책 (Rules → RAG → LLM)

## Goal
모든 요청을 LLM에 보내지 않고 필요할 때만 호출한다.

## Routing Policy
1. 룰 기반 슬롯 추출(도시/기간/예산/동행)
2. 컨텍스트 부족 시 LLM 없이 추가 질문 유도
3. RAG 결과가 충분하면 템플릿 응답 (LLM 미사용)
4. 설명 생성이 필요한 경우에만 LLM 호출

## Metrics
- `llm_used_rate`
- `chat_route_rules_total`
- `chat_route_rag_total`
- `chat_route_llm_total`

## Acceptance Criteria
- LLM 사용률 목표치(예: 20~40%) 설정 및 추적 가능
- p95 latency 목표와 사용률 간 트레이드오프가 운영 지표로 확인됨
