# B-0403 — 프롬프트/출력 스키마 강제 (JSON Schema Output)

## Goal
LLM 응답을 프론트가 즉시 렌더링 가능한 구조화 JSON으로 강제한다.

## Output Contract
- `assistant_text`
- `cards[]`: `{ type, id, title, price, why, source[] }`
- `followups[]`
- `context_used`
- `llm_used`

## Scope
- 시스템 프롬프트에 JSON only 규칙 강제
- strict parser + schema validation
- 파싱 실패 시 repair prompt 1회
- repair 실패 시 rule-template fallback

## Acceptance Criteria
- dev 기준 100회 호출 시 파싱 실패율 < 1%
- 실패 상황에서도 항상 유효 스키마 응답 반환
