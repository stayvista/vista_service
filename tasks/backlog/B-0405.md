# B-0405 — LLM 성능 제어: Queue + Concurrency Limit + Degrade

## Goal
LLM 호출 폭주 시 GPU/CPU 병목으로 전체 API가 무너지는 것을 방지한다.

## Scope
- 서비스 내부 concurrency limit (Semaphore)
- 짧은 대기열 허용 + 최대 대기시간 초과 시 자동 degrade
- fail-fast fallback 경로 표준화

## Metrics
- `llm_inflight`
- `llm_queue_depth`
- `llm_queue_wait_ms`
- `llm_reject_rate`

## Acceptance Criteria
- 폭주 상황에서도 스레드 고갈/무한 대기 없이 응답
- queue wait 임계치 초과 시 fallback 자동 동작
