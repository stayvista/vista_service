# U-0101 — web-user 홈/검색바/내비게이션(Agoda 느낌의 레이아웃, 카피 금지)



## Goal
사용자 홈 화면을 “상단 네비 + 히어로 배경 + 중앙 검색바” 형태로 구성한다.
    단, 텍스트/아이콘/배치/색상은 참고만 하고 **카피/상표/동일 문구 사용 금지**.



## Scope
- routes:
      - `/` 홈
      - `/search` 검색 결과
      - `/properties/:id` 숙소 상세
      - `/tickets` 티켓/체험
      - `/packages` 패키지
      - `/chat` 챗봇
      - `/nearby` 주변 추천
    - 홈 UI:
      - HeaderNav: 카테고리 드롭다운(숙소/티켓/패키지/체험/가이드)
      - Hero: 배경 이미지(직접 촬영/무료 스톡), 오버레이 텍스트(자체 문구)
      - SearchBar: 목적지, 체크인/체크아웃, 인원, 검색 버튼



## UX details
- SearchBar 입력 규칙:
      - 목적지 자동완성(추후) 전까지는 city list dropdown
      - 날짜: date-range picker
      - 인원: 성인/어린이 스테퍼
    - 접근성:
      - 키보드 탭 이동, aria-label
    - 반응형:
      - desktop: 한 줄
      - mobile: 2~3줄 스택



## API integration
- submit 시 `/search`로 navigate하며 querystring 생성:
      - `?city=Seoul&check_in=...&check_out=...&adults=2&children=0`
    - request_id를 응답에서 읽어 debug panel(개발모드)에서 표시(선택)



## Acceptance Criteria
- 홈에서 검색 조건을 입력하고 “검색” 클릭 시 `/search`로 이동한다
    - 상표/동일 문구/로고를 사용하지 않는다(StayVista/Wanderly 같은 자체 이름 사용)
