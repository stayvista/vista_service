# B-0001 — 모노레포 스캐폴딩 + 컨벤션 고정


## Goal
Codex가 “한 레포 안에서” 프론트/백엔드를 일관되게 작업할 수 있도록 **모노레포 구조와 규칙을 고정**한다.
이후 모든 티켓은 이 구조를 전제로 한다.


## Scope
- 레포 루트 디렉토리 구조 생성/고정
      - `web-user/` (React/Vite)
      - `web-admin/` (React/Vite)
      - `services/` (Kotlin/Spring Boot, Gradle Kotlin DSL, 멀티모듈 지향)
      - `tasks/` (티켓), `docs/`(선택), `contracts/`(OpenAPI/JSON Schema)
    - 공통 컨벤션:
      - 브랜딩: **StayVista** (내부 코드네임), UI 텍스트는 **Wanderly**(표기용) 등 상표 침해 없는 이름 사용
      - 환경변수: `.env.example`(프론트), `application.yml`(백엔드)
      - 포트/호스트 규칙(로컬): 충돌 방지 위해 명시
    - 스크립트:
      - `make dev` 또는 `./scripts/dev.sh`로 로컬 일괄 실행(선택)
    - lint/format 최소:
      - web: eslint/prettier
      - services: ktlint + detekt(선택)



## Non-goals
- CI/CD 파이프라인은 후속 티켓(B-0003~B-0004, I 티켓 역할)에서 구체화

## Acceptance Criteria
- `README.md`에 로컬 실행 방법이 한 번에 나온다.
    - 각 디렉토리(`web-user`, `web-admin`, `services`)에 최소 README가 있다.
    - Codex가 티켓을 수행할 때 “어디에 파일을 만들지” 혼동이 없다.



## Definition of Done
- [ ] 디렉토리/기본 파일 생성
    - [ ] 포트/환경변수/실행 방법 문서화
    - [ ] (선택) 공통 스크립트 추가
