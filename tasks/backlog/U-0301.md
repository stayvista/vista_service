# U-0301 — 패키지(숙소+티켓) 상세 + 구매 Saga UI



## Goal
패키지 상품을 보여주고, 패키지 HOLD/CONFIRM Saga를 통해 구매할 수 있게 한다.



## Scope
- routes:
      - `/packages` 리스트
      - `/packages/:id` 상세
      - `/checkout/package` 구매
    - UI:
      - components 요약(숙소/티켓)
      - 가격/할인 표시(v1 고정)
      - 구매 버튼 → saga hold → countdown → confirm



## API integration
- read: `GET /v1/packages`, `GET /v1/packages/{id}`
    - hold: `POST /v1/packages/{id}/holds`
    - confirm: `POST /v1/packages/{id}/confirm`



## Failure UX
- hold 단계 실패: 어떤 컴포넌트에서 실패했는지 메시지
    - confirm 단계 실패: “결제 취소/환불 처리 중” 안내(스텁)



## Acceptance Criteria
- 패키지 구매 플로우가 end-to-end로 동작한다
    - 중간 실패에도 “부분 구매”가 남지 않는다는 설명 UX가 있다
