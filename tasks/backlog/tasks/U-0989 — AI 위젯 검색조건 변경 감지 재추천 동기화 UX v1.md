# U-0989 — AI 위젯 검색조건 변경 감지/재추천 동기화 UX v1

## Goal
AI 위젯 대화 이후 사용자가 검색 조건(도시/일정/인원)을 바꿨을 때 오래된 추천을 그대로 쓰지 않도록, 변경 감지와 원클릭 재추천 흐름을 제공한다.

## Scope
- AI 위젯에 조건 변경 감지 배너 추가
- 변경 항목(도시/일정/인원)과 이전/현재 조건 요약 표시
- 원클릭 액션 제공
  - 최신 조건으로 최근 프롬프트 재추천
  - 최신 조건만 입력창에 삽입
- 재추천 실행 시 최신 검색 컨텍스트를 강제 반영

## Acceptance Criteria
- 대화 이후 검색 조건이 변경되면 위젯에서 변경 감지 배너가 노출된다
- 사용자는 클릭 한 번으로 최신 조건 기준 재추천을 실행할 수 있다
- 재추천 후에는 기준 컨텍스트가 최신값으로 갱신되어 배너가 해제된다
