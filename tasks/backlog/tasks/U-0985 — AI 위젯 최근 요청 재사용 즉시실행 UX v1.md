# U-0985 — AI 위젯 최근 요청 재사용 즉시실행 UX v1

## Goal
AI 위젯의 최근 요청 재사용을 `편집 불러오기`와 `즉시 실행`으로 분리해 반복 질문 흐름을 단축한다.

## Scope
- 최근 요청 칩을 `불러오기(초안)`/`실행` 2단 액션으로 확장
- `실행` 클릭 시 입력창 편집 없이 즉시 추천 요청 호출
- 즉시 실행 경로에서도 프롬프트 자동 패치(city/days/companions) 동작 유지
- 실행 시 source scope 자동 추론 및 추천 호출 범위 동기화

## Acceptance Criteria
- 최근 요청에서 `실행` 클릭 시 즉시 새 추천 응답이 생성된다
- 최근 요청에서 기본 클릭은 기존처럼 입력창 초안 채움 동작을 유지한다
- 즉시 실행 경로에서 자동 패치 안내와 추천 범위가 정상 반영된다
