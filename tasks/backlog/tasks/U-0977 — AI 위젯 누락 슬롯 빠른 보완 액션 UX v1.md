# U-0977 — AI 위젯 누락 슬롯 빠른 보완 액션 UX v1

## Goal
AI가 `추가 확인 필요` 상태를 반환했을 때 사용자가 질문을 다시 타이핑하지 않고, 누락 슬롯을 1클릭으로 보완해 추천 흐름을 이어가게 만든다.

## Scope
- handoff 패널에 `빠른 보완` 섹션 추가
- 누락 슬롯 기준으로 상위 3개 보완 버튼 노출
- 버튼 클릭 시 슬롯별 clarify action 또는 슬롯 프롬프트를 즉시 실행
- 기존 search patch/source scope와 연계해 보완 질문 컨텍스트 유지

## Acceptance Criteria
- 누락 슬롯이 있으면 `빠른 보완` 버튼이 자동 노출된다
- 사용자는 1클릭으로 누락 슬롯 보완 질문을 시작할 수 있다
- 보완 액션 실행 후 기존 추천 문맥(search patch/source scope)이 유지된다
