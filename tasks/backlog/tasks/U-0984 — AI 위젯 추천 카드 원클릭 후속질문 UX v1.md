# U-0984 — AI 위젯 추천 카드 원클릭 후속질문 UX v1

## Goal
AI 위젯에서 받은 추천 카드를 바로 재질문으로 확장해 재탐색 시간을 줄이고 대화 연속성을 높인다.

## Scope
- 추천 카드 영역에 `유사 추천` 액션 추가
- 저장된 추천 카드 영역에도 동일한 `유사 추천` 액션 제공
- 카드 타입(PROPERTY/PACKAGE/TICKET/POI)에 맞는 후속 질문 프롬프트 자동 생성
- 후속질문 실행 시 카드 타입에 맞는 source scope로 즉시 재추천 호출

## Acceptance Criteria
- 카드에서 `유사 추천` 클릭 시 별도 입력 없이 새로운 추천 응답이 생성된다
- 저장 카드/실시간 카드 양쪽에서 동일하게 동작한다
- 카드 타입별로 질문 문구가 달라지고 추천 범위도 해당 타입 중심으로 맞춰진다
