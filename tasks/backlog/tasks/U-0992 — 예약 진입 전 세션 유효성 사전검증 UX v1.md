# U-0992 — 예약 진입 전 세션 유효성 사전검증 UX v1

## Goal
로컬 저장 세션과 서버 Redis 세션이 어긋난 상태에서 예약 버튼을 눌러 `401 Unauthorized`가 발생하는 경험을 줄이고, 사용자에게 로그인 재진입을 먼저 안내한다.

## Scope
- 예약 진입 버튼(`지금 예약하기`) 동작 전에 서버 세션 유효성 점검
- 세션 만료/무효 시 hold/confirm API 호출 전 로그인 이동
- 예약 화면(숙소/티켓/패키지) 공통으로 동일한 사전검증 흐름 적용

## Acceptance Criteria
- 세션 무효 상태에서 `/v1/bookings/holds` 호출 전에 로그인 화면으로 유도된다
- 세션 무효 안내 문구가 예약 화면/상세 화면에서 일관되게 표시된다
- 유효 세션에서는 기존 예약 플로우를 그대로 진행한다
