# U-0988 — AI 위젯 현재 검색조건 원클릭 삽입 UX v1

## Goal
AI 도우미 입력창에서 현재 검색조건을 원클릭으로 삽입해 프롬프트 작성 시간을 줄이고, 조건 누락을 줄인다.

## Scope
- 입력창 상단에 `현재 조건 빠르게 넣기` 칩 영역 추가
- 삽입 칩 제공
  - 도시
  - 일정
  - 인원
  - 예산 힌트
  - 추천 범위
- 칩 클릭 시 입력창에 스니펫 누적 삽입 + 포커스 유지
- 동일 스니펫은 중복 삽입 방지

## Acceptance Criteria
- 사용자는 도시/일정/인원/예산/추천범위를 한 번의 클릭으로 입력창에 추가할 수 있다
- 삽입 후 즉시 추가 타이핑이 가능하도록 커서와 포커스가 입력창에 유지된다
- 동일 칩을 반복 클릭해도 동일 문구가 중복 누적되지 않는다
