# U-0981 — AI 위젯 추천 카드 타입 필터 UX v1

## Goal
AI 추천 결과가 여러 도메인(숙소/티켓/패키지/명소)으로 섞여 나올 때, 사용자가 원하는 타입만 빠르게 좁혀 보도록 탐색 효율을 높인다.

## Scope
- AI 위젯 추천 카드 영역 상단에 타입 필터 칩 추가
  - `전체`, `숙소`, `패키지`, `티켓`, `명소`
- 타입별 카드 수를 칩에 표기해 즉시 분포 확인
- 선택 타입 기준으로 카드 리스트를 실시간 필터링
- 필터 결과/전체 개수 메타 정보 표시
- 타입 전환 후 `추천 결과 보기` 동작은 현재 선택 타입 결과를 우선 적용

## Acceptance Criteria
- 추천 카드가 2개 이상의 타입을 포함할 때 타입 필터가 정상 노출된다
- 타입 칩 클릭 시 카드 목록이 즉시 해당 타입으로 필터링된다
- 타입별 개수와 현재 표시 개수가 정확히 반영된다
