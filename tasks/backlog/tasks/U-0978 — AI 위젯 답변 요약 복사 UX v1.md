# U-0978 — AI 위젯 답변 요약 복사 UX v1

## Goal
AI 답변 요약을 메신저/메모로 빠르게 공유할 수 있도록 복사 기능을 제공해, 재검색/협업 시 사용자 마찰을 줄인다.

## Scope
- 답변 영역에 `요약 복사` 버튼 추가
- 복사 성공 시 `요약 복사됨` 상태 피드백 제공
- Clipboard API 실패 시 fallback(copy command) 처리
- 복사 실패 시 사용자 경고 문구 제공

## Acceptance Criteria
- 답변이 있을 때 `요약 복사` 버튼이 노출된다
- 복사 성공 시 즉시 성공 상태가 표시되고 자동 해제된다
- 브라우저 환경 제약이 있어도 fallback 경로로 복사를 시도한다
