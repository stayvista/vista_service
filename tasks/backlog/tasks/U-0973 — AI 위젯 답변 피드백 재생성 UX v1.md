# U-0973 — AI 위젯 답변 피드백/재생성 UX v1

## Goal
AI 여행 도우미 답변 품질에 대한 사용자 피드백을 즉시 수집하고, 같은 질문을 재생성할 수 있게 해 추천 정확도 개선 루프를 만든다.

## Scope
- 답변 영역에 피드백 CTA 추가
  - `👍 도움됐어요`
  - `👎 아쉬워요`
- 동일 프롬프트 재요청 버튼 추가
  - `다시 추천`
  - 현재 source scope 유지
- 검색 적용 가드
  - `clarify_required=true` + missing slots 존재 시 검색 CTA 차단
  - 누락 슬롯 안내 + 보완 질문 자동 트리거

## Acceptance Criteria
- 사용자 피드백 클릭 시 UI 상태가 즉시 반영되고 중복 클릭이 방지된다
- `다시 추천` 클릭 시 마지막 입력 프롬프트로 재요청된다
- 누락 슬롯이 있는 상태에서 검색 CTA 클릭 시 검색이 진행되지 않고 보완 플로우로 전환된다
