# U-0994 — AI 여행도우미 플로팅 챗봇 UX v3

## Goal
AI 컨시어지를 별도 메뉴가 아닌 전역 플로팅 챗봇으로 통합해 페이지 전환 중에도 맥락을 유지하고, 검색/예약 전환 동선을 단축한다.

## Scope
- 우측 하단 고정 FAB + 확장형 챗봇 패널(데스크톱/모바일 반응형)
- 페이지 이동 후에도 챗 세션/입력 상태 유지
- `Enter` 전송 / `Shift+Enter` 줄바꿈 / 한글 IME 조합 안정 처리
- 챗 제안 액션을 검색 폼/필터/결과 영역과 양방향 동기화
- 기존 상단 AI 컨시어지 메뉴 제거 후 위젯 진입점으로 단일화

## Acceptance Criteria
- 사용자는 어느 페이지에서든 우측 하단 FAB로 동일 챗 세션을 연속 사용한다
- 엔터 입력으로 메시지 전송되며 IME 조합 중 오발송이 발생하지 않는다
- 챗봇 추천 액션 실행 시 검색 조건이 즉시 반영되고 URL과 동기화된다
- 메인/검색/상세/체크아웃 레이아웃이 챗봇 도입으로 좌우로 밀리거나 깨지지 않는다
