# U-0982 — AI 위젯 추천 카드 더보기/접기 UX v1

## Goal
AI 추천 카드가 4개를 초과할 때, 사용자가 위젯 안에서 더 많은 추천을 연속 탐색할 수 있게 카드 확장/축소 UX를 제공한다.

## Scope
- 추천 카드 목록 기본 노출 수를 4개로 유지
- 카드가 5개 이상이면 `추천 카드 더보기` 버튼 노출
- 확장 시 전체 카드 노출, 축소 시 다시 4개로 복귀
- 카드 타입 필터 전환/새 추천 생성 시 확장 상태 초기화

## Acceptance Criteria
- 카드 5개 이상일 때만 확장/축소 버튼이 표시된다
- 버튼 클릭으로 카드 노출 수가 즉시 확장/축소된다
- 타입 전환 혹은 새 추천 요청 후에는 기본(4개) 상태로 복귀한다
