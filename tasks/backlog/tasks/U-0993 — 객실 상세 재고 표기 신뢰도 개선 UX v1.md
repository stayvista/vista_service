# U-0993 — 객실 상세 재고 표기 신뢰도 개선 UX v1

## Goal
숙소 상세 화면에서 표시되는 예약 가능 상태와 실제 `지금 예약하기` 결과 간 불일치를 줄이고, 사용자가 재고 상태를 오해하지 않도록 안내 문구를 정리한다.

## Scope
- 객실 카드 가용성 계산을 `is_available=true` + `요청 객실 수 충족` 조건으로 강화
- 잔여 객실 수가 없는 경우 "예약 가능 · 실시간 재고 연동" 문구 노출 제거
- 체크아웃 화면 하단의 혼란 유발 문구(결제 직전 재검증 안내) 제거 및 상태 메시지 정리

## Acceptance Criteria
- `available_rooms`가 요청 객실 수 미만이면 상세 화면 버튼이 활성화되지 않는다
- 잔여 객실 수 미확정 상태에서는 "재고 확인 필요"로만 표시된다
- 체크아웃 화면에서 재고 마감 시 안내 문구가 간결하고 동일 톤으로 노출된다
