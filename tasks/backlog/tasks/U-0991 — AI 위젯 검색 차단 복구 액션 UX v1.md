# U-0991 — AI 위젯 검색 차단 복구 액션 UX v1

## Goal
검색 차단(`missing_slots|context_drift`)이 발생했을 때 사용자가 다음 행동을 고민하지 않도록, 차단 사유별 즉시 복구 액션을 제공한다.

## Scope
- CTA 영역에 차단 상태 경고 문구를 상시 노출
- 차단 사유별 복구 버튼 추가
  - `context_drift`: 최신 조건 재추천 실행
  - `missing_slots`: 누락 슬롯 보완 질문 진입
- 기존 검색/결과 CTA는 유지하되, 차단 상태에서 안내/복구 동선을 명확히 제공

## Acceptance Criteria
- 차단 상태에서 사용자가 복구 버튼 한 번으로 재추천 또는 보완 질문으로 진입할 수 있다
- 차단 사유에 맞는 버튼 라벨과 동작이 일치한다
- 차단 해소 후 기존 검색 핸드오프를 정상 진행할 수 있다
