# U-0903 — 인원 선택기 v2 (Rooms/Adults/Children)

## Goal
Agoda 스타일의 투숙 인원 선택 UI 제공.

## UI
- Rooms(1..8), Adults(1..16), Children(0..8)
- Children ages 입력(0..17) children 수만큼 생성
- apply/cancel

## Validation
- 최소 성인 1
- 음수/범위 초과 불가
- state는 URL query로 직렬화 가능

## Acceptance Criteria
- 메인/검색결과/상세에서 동일 컴포넌트 재사용
