# U-0974 — AI 위젯 슬롯 체크리스트/원클릭 보완 UX v1

## Goal
AI 컨시어지에서 누락된 필수 슬롯(도시/일정/동행/예산/선호)을 사용자가 즉시 인지하고, 한 번의 클릭으로 보완 대화를 이어가도록 만든다.

## Scope
- 위젯 상단에 슬롯 체크리스트 추가
  - 슬롯 완료율(%)
  - 완료/보완 상태 칩
- 슬롯 칩 클릭 시 보완 질문 자동 전송
  - 도시/일정/동행/예산/선호별 프롬프트 템플릿
- 검색 CTA 가드와 연계
  - clarify required 상태에서 누락 슬롯 보완 유도

## Acceptance Criteria
- 사용자는 현재 누락된 슬롯을 위젯에서 즉시 확인할 수 있다
- 누락 슬롯 칩 클릭 시 해당 슬롯 보완 질문이 자동 요청된다
- 슬롯 보완 후 완료율/칩 상태가 갱신된다
