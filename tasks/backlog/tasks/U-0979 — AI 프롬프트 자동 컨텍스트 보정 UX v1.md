# U-0979 — AI 프롬프트 자동 컨텍스트 보정 UX v1

## Goal
사용자 자연어 프롬프트에서 도시/일정/동행 정보를 자동 추출해 AI 추천 요청 컨텍스트에 선반영하여, 대화 왕복 횟수를 줄이고 첫 추천 정확도를 높인다.

## Scope
- 프롬프트 입력 시 자동 추출
  - 도시(서울/부산/제주/인천 및 영문 별칭)
  - 일정(예: 2박 3일, 3박, 4일)
  - 동행(가족/커플/혼자/친구)
- 추출된 값은 검색 컨텍스트 patch로 즉시 반영해 AI 요청
- 사용자에게 `자동 반영` 안내 배지/문구 노출

## Acceptance Criteria
- 사용자가 도시/일정/동행을 문장에 포함하면 AI 요청 컨텍스트에 자동 반영된다
- 자동 반영된 항목은 UI에서 즉시 확인 가능하다
- 자동 반영 실패 시 기존 동작(수동 입력 기반 추천)이 그대로 유지된다
