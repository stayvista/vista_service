# U-0900 — 메인 히어로 검색박스 v2 (Agoda-like)

## Goal
현재 메인 화면의 검색박스를 Agoda 스타일로 고도화한다:
- 탭: 숙소 / 항공+숙소 / 패키지 / 티켓
- 숙소 탭에서: 목적지(통합 자동완성) + 체크인/아웃(캘린더+가격) + 인원(객실/성인/아동) + 검색 버튼

## Current
- 목적지 dropdown 형태 + 단순 date input + 성인/어린이 input

## Deliverables
- `web-user/src/components/search/HeroSearchBox.tsx` (신규/리팩터링)
- 목적지 입력을 `UnifiedAutocomplete`로 교체
- 날짜 입력은 `PriceCalendarPopover`를 사용(2개월+가격)
- 인원 입력은 `GuestsPickerPopover`로 교체(객실/성인/아동+나이)
- Search 클릭 시 `/search`로 이동하며 querystring 유지
  - place_id, check_in, check_out, rooms, adults, children, children_ages, currency

## UX
- Enter로 검색
- 탭 변경 시 폼이 해당 도메인에 맞게 스위치(항공은 출발/도착/날짜/인원)
- 모바일: 세로 스택 레이아웃

## Acceptance Criteria
- 메인에서 검색 시작→검색 결과 페이지로 자연스럽게 전환
- 목적지/날짜/인원 선택 UI가 popover로 일관되게 동작
