# I-0401 — Local LLM Inference 서버 표준화 (Ollama)

## Goal
로컬 LLM을 서비스에 안전하게 연결하기 위한 실행 표준(구동/헬스/워밍업/교체 절차)을 확정한다.

## Decision (Default)
- 개발/로컬 기본 제공자: Ollama
- 기본 모델: `llama3.1:8b-instruct`
- 내부망 호출만 허용 (`localhost` 또는 docker network)

## Scope
- `services/docker/docker-compose.yml`에 `llm` 서비스(Ollama) 추가
- `services/infra/llm/`에 운영용 런처 스크립트/문서 추가
- `RUNBOOK.md`에 모델 다운로드/교체/워밍업/롤백 절차 명시

## Health/Readiness
- `/healthz`: inference 서버 프로세스/HTTP 응답 상태 확인
- `/readyz`: 활성 모델 로드/추론 가능 상태 확인
- `/metrics`: 최소 지연/실패 카운터 수집 경로 정의 (dev는 선택)

## Acceptance Criteria
- `docker compose`로 llm 서비스 기동 가능
- 모델 워밍업 전/후 첫 응답 지연 차이가 로그 또는 메트릭으로 확인됨
- 모델 교체/롤백 절차가 RUNBOOK에 문서화됨
