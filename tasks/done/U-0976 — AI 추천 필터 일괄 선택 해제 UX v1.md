# U-0976 — AI 추천 필터 일괄 선택/해제 UX v1

## Goal
AI가 제안한 필터를 하나씩 누르는 불편을 줄이기 위해, `전체 선택`/`전체 해제`를 제공해 검색 전환 속도를 높인다.

## Scope
- AI 추천 필터 패널에 일괄 액션 버튼 2종 추가
  - `필터 전체 선택`
  - `필터 전체 해제`
- 정렬 필터는 다중 선택이 불가능하므로 일괄 선택 시 1개만 대표 선택
- 선택 개수/활성 상태와 버튼 비활성 조건 연동

## Acceptance Criteria
- 사용자는 1클릭으로 추천 필터를 전체 적용/해제할 수 있다
- 정렬 값은 일괄 선택 시 단일 값만 적용된다
- 일괄 액션 이후 `적용 예정 필터 N개` 카운트가 즉시 갱신된다
