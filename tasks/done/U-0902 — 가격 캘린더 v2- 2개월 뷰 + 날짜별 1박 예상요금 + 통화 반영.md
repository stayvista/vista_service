# U-0902 — 가격 캘린더 v2 (2개월 + 요금)

## Goal
체크인/체크아웃 선택 팝업에서 날짜별 '예상 1박 요금'을 표시한다.

## UI
- 2개월 grid
- 선택 범위 highlight
- day cell에 price label (예: 133K)
- loading skeleton + 에러 메시지(일부 날짜 없음은 -)

## API
- `GET /v1/prices/calendar?place_id=...&from=...&to=...&currency=...&rooms/adults/children...`

## Acceptance Criteria
- popover 열면 즉시 2개월 가격 로딩
- currency 변경 시 가격이 다시 로딩/표시됨
