# I-0960 — AI 컨시어지 퍼널 관측성 v1

## Goal
메인 우측 AI 위젯 도입 이후 전환 기여도를 측정할 수 있도록 퍼널 이벤트/대시보드를 표준화한다.

## Metrics
- `ai_widget_open_total`
- `ai_widget_prompt_submit_total`
- `ai_widget_followup_click_total`
- `ai_widget_filter_apply_total`
- `ai_widget_search_handoff_total`
- `ai_widget_source_scope_total{event,scope}`
- `ai_widget_conversion_rate` (검색 진입 -> 예약완료)

## Scope
- 프론트 이벤트 로깅 포인트 정의
- `POST /v1/telemetry/events` 수집 규약 정의 및 이벤트 화이트리스트 운영
- 백엔드 chat route/latency와 연계되는 대시보드 패널 추가
- 알람 초안: 실패율, 응답지연, 위젯->검색 핸드오프 급감

## Acceptance Criteria
- 일 단위로 위젯 사용량과 검색 핸드오프율 확인 가능
- 필터칩 적용률(요청 대비 `ai_widget_filter_apply`)을 일 단위로 확인 가능
- route별(Template/LLM/Fallback) 품질 편차를 추적 가능
- RUNBOOK에 장애 대응 절차(LLM fallback 비율 급증 등) 반영
- 위젯 이벤트 수집 API rate-limit 정책이 정의되어 있음
