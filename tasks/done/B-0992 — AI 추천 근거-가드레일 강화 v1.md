# B-0992 — AI 추천 근거-가드레일 강화 v1

## Goal
AI 추천의 신뢰도를 높이기 위해 근거 없는 단정/오해 유발 문구를 줄이고, 재고·가격·환불 정책을 확정 데이터 기반으로만 안내한다.

## Scope
- 추천 결과에 근거 슬롯 필수화
  - `why_recommended[]`
  - `cautions[]`
  - `source_refs[]`
- 정책형 문구 가드레일
  - 재고/가격/환불은 실시간 API 응답값만 사용
  - 불확실 시 `확인 필요` 등급으로 강등
- 금칙 문구 룰셋
  - "확정", "보장" 등 과장 표현을 조건부로 제한
- 응답 후 검증기 추가
  - 근거 누락/금칙 위반 시 자동 리라이트 또는 fallback

## Acceptance Criteria
- 추천 카드마다 최소 1개 이상 근거와 1개 이상 주의사항이 노출된다
- 재고/가격/환불 안내는 툴 결과와 불일치할 경우 자동 차단된다
- 금칙 문구 위반률이 관측 지표로 집계되고 알람 기준을 정의한다
- fallback 응답에서도 사용자 행동 가능한 다음 액션(재검색/필터 변경)이 제공된다
