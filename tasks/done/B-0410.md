# B-0410 — LLM 포함 부하 테스트 + SLO 고정

## Goal
LLM on/off 상태에서 지연/오류 목표를 수치로 고정하고 검증한다.

## Targets (Draft)
- LLM off: p95 < 300ms
- LLM on: p95 < 1200ms
- streaming: TTFB < 500ms
- p99 보호: hard timeout 6s

## Scope
- k6 시나리오
  - spike
  - steady
  - cache-hit
- 결과 그래프/요약 리포트 생성

## Acceptance Criteria
- k6 시나리오 3종 실행 가능
- LLM 관련 지표(`llm_ms`, queue/reject/cache)와 함께 보고 가능
