# U-0990 — AI 위젯 재추천 전 검색 차단 UX v1

## Goal
AI 답변이 이전 검색 조건 기준일 때, 오래된 추천으로 바로 검색/결과 이동이 진행되지 않도록 차단하고 최신 조건 재추천을 유도한다.

## Scope
- 검색/결과 보기 CTA 공통 차단 가드 추가
  - 누락 슬롯(`missing_slots`) 차단
  - 검색조건 불일치(`context_drift`) 차단
- 차단 사유별 사용자 안내 문구 분리
  - 누락 슬롯: 어떤 정보가 필요한지 안내 + 보완질문 진입
  - 컨텍스트 드리프트: 최신 조건 재추천 요청 안내
- CTA 근처 경고 UI(재추천 필요) 노출

## Acceptance Criteria
- 검색 조건이 바뀐 상태에서 기존 AI 답변 기준 CTA를 누르면 즉시 검색 이동되지 않는다
- 차단 사유가 누락 슬롯/컨텍스트 드리프트로 구분되어 사용자에게 표시된다
- 사용자는 최신 조건 재추천 후 정상적으로 검색 핸드오프를 진행할 수 있다
