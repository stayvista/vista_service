# U-0901 — 목적지 입력 패널 v3 (Agoda-style)

## Goal
메인 화면에서 목적지 입력 focus 시 Agoda처럼 풍부한 추천 패널을 제공한다.

## Sections (MVP)
- 최근 검색(최근 선택한 place + dates + guests 요약)
- 추천 지역(도시별 district 추천)
- 명소(POI)
- 숙소(인기/스폰서 후보)
- 해당 국가의 인기 도시

## Data
- `/v1/autocomplete` q empty → popular + recent (기존)
- 추가:
  - `GET /v1/destinations/recommendations?city_id=...` (district/poi/featured)

## Acceptance Criteria
- q empty에서도 항상 의미 있는 목록이 보인다
- 선택 결과는 place_id SSOT로 저장
