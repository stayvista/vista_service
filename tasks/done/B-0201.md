# B-0201 — Ticket/Experience Catalog: product/event CRUD



## Goal
티켓/체험 상품은 숙소와 달리 “이벤트(날짜/시간)” 단위로 재고가 생긴다.
    Admin이 상품/이벤트/재고를 관리하고, User가 조회할 수 있는 API를 제공한다.



## Scope
- Admin:
      - `POST /v1/admin/tickets/products`
      - `POST /v1/admin/tickets/products/{productId}/events`
      - `PUT /v1/admin/tickets/events/{eventId}/inventory` (total 설정)
    - User:
      - `GET /v1/tickets/products`
      - `GET /v1/tickets/products/{productId}`
      - `GET /v1/tickets/events?product_id=...&date=...`
    - Search 인덱싱(선택): ticket/experience도 OpenSearch에 별도 인덱스



## Non-goals
- 좌석 지정(Seat map) 같은 고난도는 v2



## API examples
### POST /v1/admin/tickets/products
```json
{
  "name": "Wanderly City Pass",
  "category": "ATTRACTION",
  "status": "ACTIVE"
}
```
### POST /v1/admin/tickets/products/{productId}/events
```json
{
  "event_date": "2026-03-01",
  "start_time": "10:00",
  "end_time": "18:00",
  "status": "ACTIVE"
}
```



## Data model notes
- `ticket_product`, `ticket_event`, `ticket_inventory`(event 기준) 형태 권장
    - inventory는 (event_id) PK, total/reserved/sold 카운터



## Acceptance Criteria
- Admin에서 product/event 생성 후 User 조회 가능
    - inventory total 설정 API가 B-0202 HOLD에서 사용 가능
