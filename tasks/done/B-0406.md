# B-0406 — 캐시 전략: Prompt Cache / Retrieval Cache / Singleflight

## Goal
반복 질문에서 LLM 비용/지연을 줄이기 위해 다층 캐시를 적용한다.

## Scope
- Retrieval cache
  - key: `(city, intent, query_norm)`
  - value: `topK docs`
  - TTL: 5~30분
- Prompt-result cache
  - 동일 입력 1~5분 캐시
- PII 포함 질의는 캐시 제외
- stampede 방지: singleflight

## Acceptance Criteria
- 동일 질문 반복 시 `llm_ms` 감소
- 캐시 hit/miss, singleflight 동작이 메트릭으로 확인
