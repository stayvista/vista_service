# U-0987 — AI 위젯 오류 복구 액션 UX v1

## Goal
AI 추천 실패 시 사용자가 즉시 복구 경로를 선택할 수 있도록 오류 안내 UX를 강화한다.

## Scope
- 오류 배너를 액션 패널 형태로 확장
- 복구 액션 제공
  - 바로 재시도
  - 질문 복원(입력창 초안 채움)
  - 추천 범위 초기화
  - 오류 닫기
- 최근 요청 즉시실행/수동 입력과 동일한 추천 호출 경로 사용
- 복구 액션 클릭 시 로딩/입력 상태와 충돌하지 않도록 방어

## Acceptance Criteria
- 오류 발생 시 복구 버튼이 함께 노출된다
- `바로 재시도`는 마지막 프롬프트를 즉시 다시 실행한다
- `질문 복원`은 마지막 프롬프트를 입력창으로 복원하고 포커스한다
- `추천 범위 초기화`는 기본 범위(PROPERTY+POI)로 복구한다
