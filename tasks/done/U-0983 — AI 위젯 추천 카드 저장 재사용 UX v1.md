# U-0983 — AI 위젯 추천 카드 저장/재사용 UX v1

## Goal
AI 위젯 추천 카드를 저장해두고 같은 세션에서 빠르게 재열람/재이동할 수 있게 만들어 반복 탐색 효율을 높인다.

## Scope
- 추천 카드별 `카드 저장/저장됨` 토글 버튼 제공
- 저장된 카드를 별도 패널로 노출 (`저장한 추천`)
- 저장 카드에서 바로 이동 링크 실행 + 저장 해제
- 저장 상태를 로컬 상태에 보존하고 새 대화 이후에도 유지
- 저장 카드 전체 해제 기능 제공

## Acceptance Criteria
- 카드 저장 버튼 클릭 시 즉시 `저장됨` 상태로 바뀐다
- 저장된 카드는 `저장한 추천` 패널에서 다시 확인/이동할 수 있다
- 저장 해제 시 패널과 카드 상태가 즉시 동기화된다
- 새 대화를 시작해도 저장 목록은 유지된다
