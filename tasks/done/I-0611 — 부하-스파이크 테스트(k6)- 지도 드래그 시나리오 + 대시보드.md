# I-0611 — 부하/스파이크 테스트(k6): 지도 드래그 시나리오 + 대시보드

## Goal
지도 기반 Nearby는 트래픽 패턴이 독특하다(짧은 시간에 다량). 회귀 가능한 부하 테스트를 만든다.

## Scenarios
1) Steady: 50 RPS bbox 검색
2) Drag: 1 user가 10초 동안 bbox를 20번 변경(버튼 검색 포함)
3) Spike: 5초 동안 10배 증가

## KPIs
- p50/p95/p99 latency
- DB QPS/CPU
- cache hit rate
- 429 rate

## Deliverables
- `services/loadtest/k6/nearby.js`
- Grafana dashboard 패널 추가

## Acceptance Criteria
- 스테이징에서 10분 실행 시 리포트 생성/저장
