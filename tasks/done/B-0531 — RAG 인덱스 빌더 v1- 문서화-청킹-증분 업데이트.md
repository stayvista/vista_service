# B-0531 — RAG 인덱스 빌더 v1: 문서화/청킹/증분 업데이트

## Goal
runtime에서 DB를 스캔해 즉석 후보를 만드는 방식을 제거하고,
오프라인 인덱스 빌드 + 증분 업데이트로 품질/성능/일관성을 올린다.

## DB
- travel_doc(doc_id, type, ref_id, city, title, body, hash, updated_at)
- travel_doc_chunk(chunk_id, doc_id, chunk_text, hash)
- travel_doc_vec(chunk_id, model, vector_blob, updated_at)

## Pipeline
extract -> chunk -> embed -> upsert(hash)

## Acceptance Criteria
- runtime에서 DB 풀스캔 제거
- incremental build가 full 대비 10배 이상 빠름(로그 근거)
