# U-0972 — AI 위젯 세션 지속/리셋 UX v1

## Goal
AI 여행 도우미 위젯의 대화 맥락이 페이지 이동/새로고침에서 유지되도록 하여 사용 중단률을 낮추고, 사용자가 언제든 안전하게 대화를 초기화할 수 있게 한다.

## Scope
- 위젯 상태 로컬 세션 저장
  - 열림/닫힘 상태
  - 입력 draft
  - 최근 대화 메시지
  - 마지막 추천 요약/카드/후속질문
  - handoff 필터/보완질문/정렬힌트 상태
- 위젯 재오픈 시 입력창 자동 포커스 + 스레드 하단 자동 스크롤
- `새 대화` 액션 제공
  - 대화/추천/handoff 상태 초기화
  - 기본 source scope로 복귀
- 입력 UX 보강
  - Enter 전송, Shift+Enter 줄바꿈(IME 안전)
  - 입력 힌트 문구 노출

## Acceptance Criteria
- 페이지 이동 후에도 위젯 대화가 유지된다
- 브라우저 새로고침 후에도 직전 대화 상태를 복구한다
- `새 대화` 클릭 시 이전 대화/추천이 즉시 제거되고 초기 상태가 된다
- 스트리밍 중 메시지가 누적될 때 스레드가 최신 메시지로 자동 이동한다
- 한국어 IME 조합 입력 중 Enter가 오작동하지 않는다
