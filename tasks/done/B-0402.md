# B-0402 — Kotlin LLM Client (Local) + Timeout/Cancel/Streaming

## Goal
Spring Boot(Kotlin)에서 로컬 LLM 호출을 표준 클라이언트로 캡슐화한다.

## Scope
- 내부 API:
  - `LLMClient.generate(request): LLMResponse`
  - `LLMClient.generateStream(request): Stream<LLMChunk>`
- Local provider(Ollama) HTTP 호출 어댑터 구현
- Chat 도메인에서 공통 클라이언트만 사용하도록 정리

## Requirements
- timeout
  - soft timeout: 2.5s(기본)
  - hard timeout: 6s(기본)
- cancel
  - 클라이언트 연결 종료 시 inference cancel 시도
- retry
  - LLM 재시도 금지 (중복 비용 방지)
  - fail-fast + fallback 경로 제공

## Observability
- `llm_ms`(latency breakdown)
- `llm_requests_total`, `llm_errors_total`
- timeout/reject/downstream error 태그 분리

## Acceptance Criteria
- LLM 서버 down 상황에서도 chat API는 fallback 응답 반환
- soft/hard timeout을 개별 설정으로 제어 가능
- 스트리밍 호출 시 취소 이벤트가 서버 리소스 해제로 이어짐
