# U-0611 — 주변추천 지도 UI 도입: MapLibre + 2패널 레이아웃

## Goal
주변추천(POI) 화면을 “리스트 + 지도” 2패널 레이아웃으로 전환해 실서비스급 UX를 만든다.

## Why
리스트만으로는 탐색/이해가 느리고, 지도 UI가 있어야 “현재 위치 기반” 경험이 완성된다.

## Scope
- `web-user`에서 `/nearby`(또는 기존 주변추천) 페이지를 지도 중심 UX로 재구성
- 우측: 지도(MapLibre), 좌측: 결과 리스트/필터
- 모바일: 지도/리스트 탭 또는 바텀시트 전환

## Tech Decision
- 지도 라이브러리: **MapLibre GL JS**
- Tile/Style: OSM 기반(초기: 오픈 스타일, 추후 커스텀)

## UI Spec
- 상단 필터: 카테고리(관광/맛집/쇼핑/전시…), 반경, 정렬(거리/인기/평점)
- 결과 카드: 이름/카테고리/거리(미터)/썸네일(있으면)/CTA(상세보기)
- 지도: 마커 렌더링 + 선택 마커 강조

## Acceptance Criteria
- 리스트 클릭 시 지도 해당 마커로 이동/하이라이트
- 지도 마커 클릭 시 리스트에서 해당 아이템이 선택됨
- URL QueryString으로 상태 유지(카테고리/반경/좌표/줌)
