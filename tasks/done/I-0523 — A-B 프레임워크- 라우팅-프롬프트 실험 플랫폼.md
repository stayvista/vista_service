# I-0523 — A/B 프레임워크: 라우팅/프롬프트 실험 플랫폼

## Goal
라우팅 정책/리트리벌 파라미터/프롬프트를 A/B로 실험할 수 있게 만든다.

## Scope
- bucket assignment: (user_id/anon_id) -> bucket
- experiment config: feature flags + parameters
- metrics 분리 집계(0-result, fallback, latency, click proxy)

## Acceptance Criteria
- 5%/50%/100% rollout 가능
- 1분 내 롤백 가능(설정 전환)
