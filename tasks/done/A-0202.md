# A-0202 — 바우처(검표) UI + QR 입력/검증



## Goal
현장에서 QR/코드를 입력해 바우처를 1회성으로 검증(사용처리)할 수 있어야 한다.



## Scope
- voucher validate screen:
      - QR 스캔(웹캠) 또는 코드 입력
      - 결과(VALID/USED/EXPIRED/NOT_FOUND) 표시
    - (선택) 검표 로그 리스트



## API integration
- `POST /v1/admin/vouchers/validate` 또는 `POST /v1/vouchers/{id}/redeem`
    - 응답 코드:
      - 200 VALID
      - 409 ALREADY_USED
      - 409 EXPIRED
      - 404 NOT_FOUND



## Acceptance Criteria
- 동일 바우처를 2번 검증하면 1번만 성공해야 한다(서버 상태전이 보장)
