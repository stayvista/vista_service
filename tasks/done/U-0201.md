# U-0201 — 티켓/체험 탐색 + 구매 플로우



## Goal
사용자가 티켓/체험 상품을 탐색하고 이벤트(날짜/시간)를 선택해 HOLD→CONFIRM으로 구매할 수 있게 한다.



## Scope
- routes:
      - `/tickets` 리스트
      - `/tickets/:productId` 상세
      - `/checkout/ticket` 구매
    - UI:
      - ProductCard, CategoryTabs
      - EventPicker(날짜/시간)
      - QuantityStepper
      - Checkout(결제 스텁)



## API integration
- list: `GET /v1/tickets/products`
    - detail: `GET /v1/tickets/products/{id}`, events: `GET /v1/tickets/events`
    - hold: `POST /v1/tickets/orders/holds`
    - confirm: `POST /v1/tickets/orders/{id}/confirm`



## Edge cases
- sold out: 409 TICKET_SOLD_OUT → 다른 시간/날짜 제안
    - hold countdown: booking과 동일 UX(재사용 컴포넌트)



## Acceptance Criteria
- 티켓 상품을 선택해 구매 완료까지 흐름이 이어진다
