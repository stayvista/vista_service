# U-0980 — AI 위젯 최근 요청 재사용 UX v1

## Goal
사용자가 이전에 입력한 요청을 다시 타이핑하지 않고 재사용할 수 있게 해, 반복 탐색(도시/조건 비교) 시간을 단축한다.

## Scope
- AI 위젯에 `최근 요청 다시 쓰기` 칩 목록 추가(최대 5개)
- 최근 사용자 프롬프트를 중복 제거 후 최신순으로 표시
- 칩 클릭 시 프롬프트 입력창에 즉시 채우고 포커스 이동
- 긴 문장은 칩에서 축약 표시, 원문은 title로 제공

## Acceptance Criteria
- 최근 요청이 존재하면 재사용 칩이 자동 노출된다
- 칩 클릭만으로 프롬프트 입력이 채워지고 즉시 수정/전송 가능하다
- 중복/너무 짧은 요청은 목록에서 제외된다
