# U-0614 — 마커 클러스터링 + 카운트 스타일 + 줌 인 동작

## Goal
줌아웃 시 마커가 겹치지 않도록 클러스터링을 적용한다.

## Implementation
- MapLibre GeoJSON Source `cluster: true`
- cluster circle layer + count symbol layer
- cluster 클릭 시:
  - 해당 cluster 확장 줌으로 이동(또는 getClusterExpansionZoom 사용)

## Acceptance Criteria
- 줌 5 이하에서도 화면이 과밀하지 않음
- cluster 클릭 시 자연스럽게 확대되며 마커가 분해됨
