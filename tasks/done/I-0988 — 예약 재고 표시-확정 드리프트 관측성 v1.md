# I-0988 — 예약 재고 표시-확정 드리프트 관측성 v1

## Goal
상세 화면 가용성 표시와 실제 hold/confirm 결과 간 드리프트를 계량하기 위해 재사용/만료정리 지표를 운영 관측 항목에 포함한다.

## Scope
- 메트릭
  - `booking_hold_reused_total`
  - `booking_hold_expired_released_total`
- 관찰 포인트
  - 반복 클릭 사용자에서 hold 재사용률
  - 만료 hold 즉시 정리 건수 추이
  - 재고 마감 오류(`BOOKING_OVERBOOKED`)와의 상관 분석

## Acceptance Criteria
- 대시보드에서 hold 재사용/만료정리 추이를 확인할 수 있다
- `BOOKING_OVERBOOKED` 급증 구간과 함께 원인 분석이 가능하다
- 운영 런북에 재고 드리프트 1차 확인 지표로 반영할 수 있다
