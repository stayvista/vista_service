# U-0960 — 홈 우측 AI 컨시어지 위젯 v2

## Goal
기존 `/chat` 탭 중심 UX를 메인 홈 우측의 대화형 위젯으로 전환해 검색/예약 전환율을 높인다.

## Scope
- 메인 히어로 우측에 `AI 여행 도우미` 위젯 고정 배치(Desktop)
- 모바일은 FAB(플로팅 버튼) + Bottom Sheet 패널 제공
- 빠른 프롬프트 칩(숙소/가족/맛집/일정/패키지) 제공
- 추천 카드/후속 질문/요약/검색 이동 CTA 제공
- AI가 제안한 검색 필터칩(선택/해제) UI 제공
- 선택한 AI 필터를 검색 URL 파라미터와 동기화(검색 페이지 필터 패널 즉시 반영)
- 상단 네비게이션에서 `AI 컨시어지` 메뉴 제거
- 위젯 이벤트 전송(오픈/요청/후속질문/필터적용/검색핸드오프/결과보기)

## Acceptance Criteria
- 홈 화면에서 별도 페이지 이동 없이 AI 추천 요청/결과 확인 가능
- 대화 결과에서 숙소/티켓/패키지/지도로 즉시 이동 가능
- 모바일에서 챗 패널 열기/닫기 동작이 정상이고 스크롤/포커스가 깨지지 않음
- AI 필터칩 선택 상태가 `조건으로 숙소 검색` 버튼에 반영되어 실제 검색 조건으로 전달됨
- 이벤트 수집 실패 시에도 사용자 플로우가 중단되지 않음(soft-fail)
