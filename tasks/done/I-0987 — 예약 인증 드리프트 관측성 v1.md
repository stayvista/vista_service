# I-0987 — 예약 인증 드리프트 관측성 v1

## Goal
클라이언트 로그인 상태와 서버 세션 상태가 불일치해 예약 API에서 인증 실패가 발생하는 패턴을 관측 가능한 지표로 수집한다.

## Scope
- 메트릭: `auth_guard_reject_total{reason,path_group}`
- 분석 포인트
  - `path_group=bookings` 인증 거절 추이
  - `path_group=me` 세션 프로브 실패 추이
  - 인증 실패 후 로그인 재진입 전환율(프론트 이벤트와 결합)

## Acceptance Criteria
- 대시보드에서 예약 경로 인증 실패 건수를 시간대별로 조회할 수 있다
- `bookings`/`me` 경로군별 분리 집계가 가능하다
- 인증 실패 급증 시 알람 룰 추가를 위한 기준 지표를 제공한다
