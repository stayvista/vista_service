# U-0975 — AI 위젯 응답 생성 중단 UX v1

## Goal
AI 추천 응답이 길어질 때 사용자가 즉시 생성을 중단하고 다음 액션(조건 수정/재요청)으로 빠르게 전환할 수 있게 만든다.

## Scope
- 위젯 생성 상태에서 `생성 중단` 버튼 제공
- 스트리밍/일반 추천 요청 모두 AbortController로 취소
- 요청 취소 후 UI 상태 정리
  - loading/streaming 상태 해제
  - 취소 안내 메시지 표시
  - stale 응답 반영 방지

## Acceptance Criteria
- 생성 중 버튼 클릭 시 1초 이내에 생성 상태가 종료된다
- 취소된 요청의 늦은 응답이 위젯에 반영되지 않는다
- 사용자는 취소 직후 프롬프트 수정 및 재요청을 바로 수행할 수 있다
