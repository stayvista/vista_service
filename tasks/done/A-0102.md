# A-0102 — 숙소/룸타입 관리 UI(등록/수정)



## Goal
Admin에서 숙소와 룸타입을 생성/수정할 수 있어야 한다.



## Scope
- Properties list:
      - 테이블(이름/도시/상태/수정)
      - 검색(도시/키워드)
    - Property form:
      - name, address, lat/lng, status
    - RoomType form:
      - name, max_guests, base_price, status
    - optimistic save + toast



## API integration
- create/update:
      - `POST /v1/admin/properties`
      - `PATCH /v1/admin/properties/{id}`
      - `POST /v1/admin/properties/{id}/room-types`
      - `PATCH /v1/admin/room-types/{id}`
    - 에러 처리:
      - 400 validation → 필드 에러 표시



## Acceptance Criteria
- 숙소/룸타입 생성 후 User 상세에서 확인 가능(B-0101 연동)
